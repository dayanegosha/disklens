# .демо

искусственный набор из девяти файлов объёмом около 10 МиБ: фотографии, архив, документы и две группы дубликатов. расширения нужны для примера, содержимое генерируется из повторяемых байтов.

после установки disklens запусти из корня репозитория:

```sh
python examples/demo.py
```

скрипт создаёт временные файлы, действительно сканирует их и сохраняет [`report.html`](report.html) и [`report.json`](report.json). исходные файлы удаляются вместе с временной папкой; в отчёте остаются вымышленные пути.

`report.html` открывается двойным кликом и работает без интернета. повторный запуск обновляет оба демонстрационных отчёта.
